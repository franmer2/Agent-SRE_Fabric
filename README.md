# Microsoft Fabric monitoring

Reusable Microsoft Fabric SRE accelerator for monitoring capacities,
workspaces, items, and Capacity Unit consumption through Azure SRE Agent.
It includes a responsive bilingual Live Report, optional historical analytics,
Power BI PBIP/TMDL assets, deployment automation, and guarded operational
workflows.

The solution is read-only by default. Any optional write operation requires
explicit approval and produces an audit record.

![Microsoft Fabric monitoring Live Report](docs/assets/live-report-overview.png)

*Responsive bilingual overview of Fabric capacities, workspaces, items, CU
consumption, and operational alerts.*
