# Surveillance Microsoft Fabric / Microsoft Fabric monitoring

## Français

Accélérateur SRE Microsoft Fabric réutilisable pour surveiller les capacités,
les espaces de travail, les artefacts et la consommation des unités de capacité
avec Azure SRE Agent. Il comprend un Live Report bilingue et responsive, une
analyse historique optionnelle, des composants Power BI PBIP/TMDL, des outils
de déploiement et des workflows opérationnels protégés.

La solution fonctionne en lecture seule par défaut. Toute opération d'écriture
optionnelle exige une approbation explicite et produit une trace d'audit.

## English

Reusable Microsoft Fabric SRE accelerator for monitoring capacities,
workspaces, items, and Capacity Unit consumption through Azure SRE Agent. It
includes a responsive bilingual Live Report, optional historical analytics,
Power BI PBIP/TMDL assets, deployment automation, and guarded operational
workflows.

The solution is read-only by default. Any optional write operation requires
explicit approval and produces an audit record.

![Microsoft Fabric monitoring Live Report](docs/assets/live-report-overview.png)

*Vue bilingue et responsive des capacités, espaces de travail, artefacts,
consommations CU et alertes opérationnelles / Responsive bilingual overview of
Fabric capacities, workspaces, items, CU consumption, and operational alerts.*
